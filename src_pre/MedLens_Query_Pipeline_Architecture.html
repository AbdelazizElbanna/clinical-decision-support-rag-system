Architecture · Query Pipeline

MedLens AI — from request to response

Trace of a single user query through intent extraction, retrieval, reranking, and grounded generation. Ten stages, one routing fork.

1
Entry
main.py

POST /api/query or /api/query/stream receives the raw query, the caller's patient_profile (age, gender, notes), and chat_summary (multi-turn working memory). Delegates to run_pipeline().

2
Intent Extraction
intent_extractor.py

An LLM call structures the raw query into a typed object used to route and scope everything downstream.

is_medical_query
routes to RAG path or direct-reply path
condition
Eczema / Psoriasis / Urticaria / Unknown
collections_to_query
which vector collections to hit
requires_weather
gate for weather enrichment
search_query_en
translated / cleaned English query
3
Routing Fork
pipeline.py

If is_medical_query is false, the pipeline short-circuits. Otherwise it proceeds through retrieval below.

if non-medical Direct LLM reply — greeting or chit-chat. Language picked from a Unicode range check. No retrieval, no weather, no RAG. Prompt returns straight to Generation (step 9).
4
Weather Enrichment
weather_service.py

Runs only if requires_weather is true and a governorate was extracted. Resolves governorate → lat/lon, fetches live temperature, humidity, UV index, wind speed, dust, and PM2.5.

5
Retrieval
retriever.py

Queries the relevant Chroma collections:

  • Diseases (medical_guidelines) — encoded with all-MiniLM-L6-v2
  • Drugs — encoded with BAAI/bge-m3

Candidate count is fixed inside the retriever — 20 for diseases, 10 for drugs — independent of the caller's requested count.

Retrieval is called with the raw query, not search_query_en from step 2 — the rewritten query is computed but not used in this call path.
6
Reranking & Scoring
pipeline.py

A cross-encoder (ms-marco-MiniLM-L-6-v2) scores each candidate against the query, for every collection except drugs. Scores are then min-max normalized into a randomized target band before ranking.

Chunks scoring below 0.25 are dropped. Remaining chunks are deduped by exact text and capped at 4 per collection.

7
Context Assembly
pipeline.py

Blocks concatenated in fixed order:

  • Patient profile — age, gender, notes
  • Conversation context — working memory
  • Weather context — live metrics, if fetched
  • Source blocks — one per selected chunk
  • Medication context — current / considered
8
Prompt Construction
pipeline.py

SYSTEM_PROMPT (grounding rules, refusal phrase, output format) + assembled context + patient query + a mandatory language instruction.

9
Generation
groq_router.py

Prompt sent to Groq. The router holds a pool of API keys and rotates on rate-limit or failure. The streaming endpoint yields tokens incrementally; the standard endpoint returns the full completion.

10
Response Packaging
pipeline.py

Returns the answer text, a sources[] list (every candidate chunk, scored, flagged selected or not), and a pipeline_trace object — consumed by the frontend evidence panel.
